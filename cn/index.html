Easy Pump Fun API 文档

在 pump.fun 上买入和卖出的最简单方式！复制、粘贴、运行。把精力留给你的交易算法，其余交给 Easy Pump Fun。

零配置

自动配置 RPC 节点，管理程序地址、代币账户、联合曲线（bonding curve）以及手续费等细节。

零日志政策

你的数据始终归你所有。不追踪、不存储，永不例外。所有请求均采用端到端加密。

免费 RPC 节点

无需任何配置。免费版提供共享 RPC 节点；高级用户可使用专属节点，速度更快、更稳定。

Easy Pump Fun 的设计初衷就是简单易用：只需调用端点并传入必要参数，即可完成交易。API 会自动配置 RPC 节点（所有用户免费）、管理所有程序地址和代币程序、自动创建和关闭代币账户、连接联合曲线（bonding curve）、处理计算单元（Compute Units）和 microLamports 等细节。

为增强安全性，Easy Pump Fun 对所有请求启用端到端加密，并支持 IP 白名单访问控制（仅订阅套餐可用）。

订阅用户可获得账户专属的独立 RPC 节点，不会因其他用户而出现瓶颈。

高级 API 提供代币狙击、服务可用性保障（SLA）、更高的调用频率限制以及优先技术支持等高级功能。请联系 support@easypumpfun.com

如有其他疑问，欢迎随时联系 support@easypumpfun.com

3. 响应

3.1 响应状态码

状态码：200

响应状态码 200 表示 API 运行正常，正在按预期处理请求。其他任何状态码都说明 API 出现了问题。需要注意的是：即使状态码为 200，交易本身仍可能失败。这说明 API 工作正常，但交易因配置不当或其他原因未能完成。

3.2 响应正文 

{
    "failed": {
        "message": null,
        "status": false
    },
    "signature": "4ci6dTW6D6ocnKiT8qzD9Bg89wpWx5KeXW2h8JTqeZfk6zKF81AbYUnKuEcTQmdma7Q2mBnutZEW89ZCYpADfzo1"
}

failed

该字段表示交易是否失败，包含两个子字段：

  • message 交易失败时的问题描述。若交易成功，该字段为 None。
  • status 布尔值，表示交易是否失败。False 表示未失败；True 表示失败。

signature

已完成交易的哈希值。如果交易失败，当 API 已成功处理请求但交易本身完成失败时，该字段仍可能出现。

4.2 SOL 数量

sol_in

float 仅买入

你想用于买入该代币的 SOL 数量。

"sol_in": 0.3（用 0.3 SOL 买入）

percentage

float 仅卖出

你想卖出的代币持仓百分比。

"percentage": 50（卖出 50% 的代币）

slippage

float

交易可接受的滑点百分比。数值越高，交易成功的概率越大。

"slippage": 2（如果不确定，设为 2% 即可）

滑点可以理解为：买卖时允许价格出现一定幅度的波动。举个例子，假设你把滑点设为 0%，准备用 1 SOL 买入 X 数量的代币。但在交易确认前，可能有其他人也在买入，从而推高价格。如果这期间代币价格上涨了 1%，那么 X 数量代币的成本就变成 1.01 SOL。由于你的交易只允许支付 1 SOL，而代币此时价值 1.01 SOL，交易就会失败。同样的例子，如果你把滑点设为 2%，相当于告诉系统：为了买到这 X 数量的代币，我愿意最多多付 2%。因此当价格上涨到 1.01 SOL 时，交易可以成功，你实际支付 1.01 SOL。注意此时你只多付了 1%，并未用满 2% 的滑点额度。如果价格涨幅超过 2%，例如达到 1.03 SOL，交易仍会失败。简单来说，滑点就是你愿意为成交而接受的最大价格偏差。交易越活跃的代币，通常需要设置更高的滑点。但也不宜设得太高，以免多付。如果你不确定，直接设为 2% 即可。

以上参数均为必填项，缺少任一参数 API 都无法正常工作。手续费设置有两种方式：一是直接指定 SOL 金额，由系统自动计算；二是手动填写计算单元（compute）和 microLamports。两种方式必须二选一，否则交易无法完成。

4.3 交易手续费

Easy Pump Fun API 本身不收取任何费用。但每笔交易你都需要额外向 Pump Fun 支付交易金额 1% 的费用（这一点无法避免）。此外，如果你是首次买入某个代币，还会被收取略高于 0.002 SOL 的费用，用于在你的钱包中创建代币账户（同样无法避免）。

sol_fee

float

你想用于支付手续费的 SOL 数量，将附加在交易成本之上。

"sol_fee": 0.0001

请注意：以这种方式配置手续费时，实际费用可能并不精确，但会大致接近所指定的数值。

compute

int

该交易可使用的最大计算单元数量。

如果你设置了 "sol_fee"，则无需设置此项。

"compute": 100_000

mlamports

int

单个计算单元的费用，以 microLamports 计。

如果你设置了 "sol_fee"，则无需设置此项。

"mlamports": 2_000_000
